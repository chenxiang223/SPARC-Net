# 3D-CNN Reproduction

This folder contains a runnable PyTorch reproduction entry for the 3-D CNN hyperspectral baseline. The implementation is provided in `../common/model_zoo.py` and follows the 3-D spectral-spatial convolution family used by open HSI classification codebases such as https://github.com/eecn/Hyperspectral-Classification.

Run this method alone with `run_reproduction.py`.
